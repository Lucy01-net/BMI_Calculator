*BMI Calculator*

A simple, web‑based Body Mass Index (BMI) calculator built with HTML, CSS, and JavaScript. 
Users can enter their height and weight to instantly receive their BMI value and corresponding health category.

*Features*

Instant BMI calculation
Clear health category feedback
Clean, responsive UI
Lightweight and fast

*How It Works*

The calculator uses JavaScript to:
Capture user input for height and weight
Apply the BMI formula:
BMI = weight (kg) / height² (m²)
Display the BMI result and category (Underweight, Normal, Overweight, Obese)
Update the UI dynamically based on user input

*Tech Stack*

HTML — structure
CSS — styling
JavaScript — calculation logic and dynamic updates
